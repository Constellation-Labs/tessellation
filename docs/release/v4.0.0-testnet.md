## Action Required for Metagraph Operators

**This release includes breaking changes that require metagraph updates.**

The Merkle Patricia Trie (MPT) state migration changes the global snapshot format. All metagraph operators must update their metagraphs to remain compatible with the network. See [metagraph-upgrade-guide.md](metagraph-upgrade-guide.md) for detailed migration steps.

### State Proof System Switch

At testnet ordinal **3,070,000**, the global snapshot state proof system transitions from **Legacy format** (16 individual hash fields) to **Merkle Patricia Trie format** (single MPT root hash).

- **Ordinals <= 3,070,000**: `LegacyFormat` - `GlobalSnapshotStateProof` with 16 individual hash fields computed via Merkle tree
- **Ordinals > 3,070,000**: `MerklePatriciaFormat` - `GlobalSnapshotStateProof` with a single `mptRoot: Option[Hash]`

This is controlled by `GlobalStateProofSelector` in `modules/shared/src/main/scala/io/constellationnetwork/schema/StateProofSelector.scala`. Currency snapshots are **not affected** - `CurrencyStateProofSelector` always returns `LegacyFormat`.

MainNet and IntegrationNet ordinals are set to `Long.MaxValue` (not yet scheduled).

## What's New

### Merkle Patricia Trie (MPT) State Proofs
Cryptographic state proofs for global snapshots using Merkle Patricia Tries, enabling:
- Efficient verification and state recovery
- Cryptographic proofs of state inclusion
- Foundation for light client support

Key implementation:
- `MptStore` - Interface to the trie storage (`modules/shared`)
- `FileSystemMerklePatriciaProducer` - Persistent trie producer (`modules/node-shared`)
- `StateProofSelector` / `StateProofBuilder` - Format selection and proof construction
- Incremental MPT updates (only changed fields, not entire state)
- Parallel MPT producer optimization

### Consensus Improvements
- FSM-based consensus architecture
- Randomized facilitator selection to reduce round stalls
- Improved fork detection using snapshot hash
- Fixed CPU starvation issues during consensus

### Delegated Stakes
- Incremental delegated staking support (activates at ordinal 3,070,000 on testnet)
- Ability to increase existing delegated stakes

### Observability
- ClickHouse structured logging support for centralized monitoring
- Configurable via environment variables

### Tooling
- New `TransactionGenerator` tool for load testing DAG transaction throughput
