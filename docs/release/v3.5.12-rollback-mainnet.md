# MainNet Notice: Reverting to v3.5.12

**Target:** MainNet
**Version:** v3.5.12
**Date:** March 2026

---

## Action Required

**Do not upgrade to v4.0.0.** MainNet is reverting to v3.5.12 while additional stabilization work is completed.

If you have already upgraded, please follow the rollback steps below.

---

## Background

After deploying v4.0.0 to MainNet, we identified consensus performance issues under MainNet-scale conditions that were not surfaced during Testnet and IntegrationNet validation. Out of an abundance of caution, we are reverting MainNet to v3.5.12 while we address these.

---

## Rollback Steps

1. **Stop** all Tessellation processes (L0 and L1)
2. **Replace JARs** with v3.5.12 versions — [download here](https://github.com/Constellation-Labs/tessellation/releases/tag/v3.5.12)
3. **Revert to Java 11** if you upgraded to Java 21 for v4.0.0
4. **Restart** your node with your previous configuration
5. **Verify** your node is running v3.5.12:
   ```bash
   curl -s http://localhost:9000/cluster/info | jq '.[0].version'
   ```

### Metagraph Operators

If you updated your metagraph for v4.0.0, revert your Tessellation dependency to v3.5.12, revert to Java 11, and rebuild. If you had not yet updated, no action is needed.

---

## What's Next

v4.0.0 features including MPT state proofs and delegated staking will continue validation on Testnet and IntegrationNet. A revised MainNet timeline will be shared once ready.

For questions, reach out via the official Constellation Network channels.
